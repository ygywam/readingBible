# 회정교회 성경 대행진 웹앱 (2026)

회정교회 전교인이 함께하는 초고속 성경읽기 웹앱입니다.
기존 Google Apps Script + Google Sheets 구조에서 **Supabase (PostgreSQL) + Vercel**로 전환하여 압도적인 반응 속도와 안정성을 제공합니다.

## ✨ 주요 기능
- **초간편 원터치 기록 (내 성경):** 읽은 곳까지 클릭 한 번으로 일괄 입력 및 개별 취소 지원
- **소그룹 대항전 & 개인별 순위 (대행진 트랙):** 0.05초 초고속 실시간 랭킹 트랙 및 소그룹 상세 팝업
- **오늘의 묵상 나눔:** 성도 간 말씀 묵상 공유 및 실시간 좋아요(하트) 반응
- **관리자 기능:** 실시간 공지사항 작성(에디터), 새 성도 등록, 명부 검색 및 비밀번호 초기화
- **다양한 테마 & 글자 크기 조절:** 성도 맞춤형 UI/UX 및 모바일 완벽 최적화
